# Vorpet

> Виртуальный питомец и ИИ-ассистент

## О проекте

**Vorpet** — это браузерное расширение с интерактивным ИИ-питомцем, который живёт у тебя в браузере и помогает работать с контентом страниц. Питомец умеет пересказывать статьи, отвечать на вопросы по открытой странице и просто составлять компанию.

### Ключевые фичи

- **Быстрый пересказ** — выдели текст или открой статью, питомец перескажет суть за секунды
- **Q&A по странице** — задавай вопросы по содержимому открытой вкладки
- **Питомец с характером** — анимированный персонаж с реакциями и настроением
- _(в будущем)_ История взаимодействий и прокачка питомца
- _(в будущем)_ Поддержка нескольких питомцев
